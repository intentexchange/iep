# `@iep/spec`

Intent Exchange Protocol v0.2: JSON Schemas, Ed25519, RFC 8785 JCS, complement predicates, and the session state machine.

```bash
yarn add @iep/spec
```

```ts
import {
  IEP_VERSION,
  REFERENCE_DISCOVERY_URL,
  parseIntentDocument,
  verifyDidSignature,
} from "@iep/spec";
```

Canonical spec: [intentexchange.dev/protocol](https://intentexchange.dev/protocol).
Reference Discovery: [discovery.intentexchange.dev](https://discovery.intentexchange.dev).
Source: [github.com/intentexchange/iep](https://github.com/intentexchange/iep).

Apache-2.0.
